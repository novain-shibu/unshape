# Sources of the measured public documents (v0.1.0; files are NOT redistributed)

Used for measurement only, on 2026-10-16. All were public documents from official websites, downloaded once, politely
(3 s apart). Since 2026-10-20 this project no longer uses government documents as test data, and the earlier link list
has been removed from this file.

- prs_1 .. prs_11: 11 Kerala legislative PDFs (ordinances and one bill) published on prsindia.org
- air_1, ku_1 .. ku_4: 5 Microsoft Print-to-PDF files (one public-broadcaster news text, four university press releases)
- lsg_1 .. lsg_10: 10 public orders from a Kerala state department website (unseen-source test)

Later versions (v0.2.0 onwards) are tested on documents we made ourselves from Wikipedia text (CC BY-SA 4.0), and on a
few non-sensitive web PDFs; each test is listed in the README.
